## About Caption Studio Tools

Caption Studio Tools is a browser-accessible HTML toolkit designed around caption-related work inside studio-style workflows. It focuses on keeping the experience simple: open it in a web environment, use the available caption utilities, and work through tasks without installing a separate desktop application.

The project is arranged as a lightweight static site, which makes it straightforward to publish, maintain, and reuse across hosting setups. It is a practical fit for teams or individuals who want a small web-first tool that can be served directly from a repository with minimal setup.
